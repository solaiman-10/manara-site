# منارة + مدارك — منصتان تعليميتان بمستودع واحد

المستودع يحتوي **مشروعين منشورين من نفس المستودع**:
- **المنارة** — مجلد `manara-site/` (منصة دروس إضافية بملف واحد)
- **مدارك** — مجلد `madark/` (موقع تسويقي متعدد الصفحات + لوحات تحكم)

كلاهما يعمل **بالخادم أولاً** (Netlify Functions) مع نسخة احتياطية محلية في المتصفح عند انقطاع الاتصال.

## الملفات

- `manara-site/index.html` — النسخة النهائية للمنارة (مصدر الحقيقة)
- `app.html` — نسخة مرآة قديمة للمنارة (تُحدَّث بالنسخ من `manara-site/index.html`)
- `madark/` — مشروع مدارك مستقل: صفحات + `madark/netlify/functions/madark-api.js`
- `netlify/functions/manara-api.js` — واجهة خادم المنارة (مشتركة في جذر المستودع)
- `netlify.toml` — إعدادات مشتركة (لا تحدد دليل النشر؛ يتحكم كل موقع به من لوحة Netlify)

## النشر التلقائي (Git + Netlify) — موقعان

### موقع المنارة
- **Publish directory:** `manara-site`
- **Functions directory:** `netlify/functions`
- النتيجة: `https://manara-1.netlify.app`

### موقع مدارك
- **Publish directory:** `madark`
- **Functions directory:** `madark/netlify/functions`
- النتيجة: `https://madark-1.netlify.app`

### تحديث الموقعين بعد كل تعديل
```
# مزامنة النسخة المرآة للمنارة
Copy-Item manara-site/index.html app.html -Force

git add -A
git commit -m "وصف التعديل"
git push
```
كلا الموقعين يتحدثان تلقائياً مع كل push.

## الحسابات الحقيقية

- تسجيل بالبريد الإلكتروني أو **رقم الجوال السعودي + رمز OTP** (رسالة نصية).
- تسجيل المعلم يتطلب **رفع شهادة التخصص** (صورة أو PDF حتى 2MB) — يُنشأ بحالة `pending`.
- **المالك فقط** يعتمد أو يرفض المعلمين، ويرى الإحصائيات الحقيقية داخل لوحته.

### بيانات المالك الافتراضية
| المنصة | البريد | كلمة المرور |
|---|---|---|
| المنارة | `admin@manara.edu` | `admin123` |
| مدارك | `admin@madark.edu` | `madark2026` |

تُغيَّر عبر متغيرات البيئة (أدناه) أو من لوحة الإعدادات داخل التطبيق.

## لوحة إعدادات المالك

- **المنارة:** زر "أنت المالك؟" في شاشة الدخول → إعدادات المظهر والأسعار وطرق الدفع، **إحصائيات المنصة**، **طلبات المعلمين** (عرض الشهادة/اعتماد/رفض)، **سجل المستخدمين والحصص** مع زر تنزيل ملف المراجعة.
- **مدارك:** `admin.html` → نفس الأقسام، مع إحصائيات حقيقية (مستخدمون/طلاب/معلمون/حجوزات) لا تظهر إلا للمالك.

## متغيرات البيئة (Netlify → Site settings → Environment variables)

| المتغير | المنصة | الوصف |
|---|---|---|
| `TWILIO_ACCOUNT_SID` | كلتاهما | معرف حساب Twilio (اختياري) |
| `TWILIO_AUTH_TOKEN` | كلتاهما | رمز Twilio السري (اختياري) |
| `TWILIO_FROM` | كلتاهما | رقم المرسل في Twilio (اختياري) |
| `MADARK_OWNER_EMAIL` / `MADARK_OWNER_PASSWORD` | مدارك | بيانات المالك |
| `MANARA_OWNER_EMAIL` / `MANARA_OWNER_PASSWORD` | المنارة | بيانات المالك |

> **وضع OTP التجريبي:** بدون إعدادات Twilio لا تُرسل رسالة، بل يُظهر الخادم الرمز في استجابة `sendOtp` وتُعبَّئه الواجهة تلقائياً — مثالي للتجربة قبل إدخال بيانات Twilio الحقيقية.

## التخزين

- حسابات/جلسات/حجوزات/OTP تُخزَّن في **Netlify Blobs** (مدارك: store `madark-data`، المنارة: store `manara-data`).
- كلمات المرور مشفرة `scrypt + salt` — لا تُخزَّن نصاً أبداً.
- رموز OTP صلاحيتها 5 دقائق، وإعادة الإرسال بعد دقيقة.

## تفعيل الدفع الحقيقي عبر Moyasar

1. أنشئ حساب تاجر في **https://moyasar.com/ar** ثم الداشبورد: https://dashboard.moyasar.com/register/new.
2. خذ **Publishable API Key** من الداشبورد (يبدأ بـ `pk_test_` للتجربة أو `pk_live_` للاستقبال الفعلي).
3. داخل التطبيق: دخول المالك → لوحة الإعدادات → قسم "بوابة الدفع (Moyasar)":
   - الصق المفتاح في "مفتاح النشر".
   - في "رابط العودة" ضع رابط موقعك أو اتركه فارغاً ليُستخدم الموقع الحالي تلقائياً.
   - اضغط "حفظ الإعدادات".
4. جرب أولاً بمفتاح تجريبي وبطاقات الاختبار: https://docs.moyasar.com/guides/card-payments/test-cards
   (مثال: `4111111111111111` / أي تاريخ مستقبلي / أي CVV).
5. للاستقبال الفعلي استبدل المفتاح بـ `pk_live_...` — **يتطلب موقعاً HTTPS** (Netlify يوفره تلقائياً).

> ملاحظة أمنية: مفتاح النشر آمن للوضع في التطبيق. أما **Secret Key** فلا تضعه أبداً في الكود — يُستخدم فقط من خادم للتحقق من الدفع.

## بطاقات اختبار Moyasar

- بطاقة ناجحة: `4111111111111111`
- بطاقة مرفوضة: `4000000000000002`

## التجربة محلياً

افتح `manara-site/index.html` (المنارة) أو `madark/index.html` (مدارك) بالنقر المزدوج، أو شغّل خادماً محلياً:
```
python -m http.server 8000
```
ثم افتح `http://localhost:8000` في المتصفح.

> ملاحظة: ميزات الجوال + OTP تتطلب الاتصال بالخادم (Netlify Functions) للعمل بكاملها؛ عند فتح الملف محلياً ستشاهد رسالة "يتطلب الاتصال بالخادم".
