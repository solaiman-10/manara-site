# منارة — منصة دروس إضافية

تطبيق صفحة واحدة (HTML + CSS + JS) لمساحة تعليمية تقدم دروساً إضافية لطلاب التعليم العام. يعمل بالكامل بدون خادم ويحفظ الإعدادات في متصفح كل مستخدم.

## الملفات

- `app.html` — ملف التطبيق الرئيسي (ساعة العمل اليومية)
- `manara-site/index.html` — نسخة النشر (تحدَّثها بعد كل تعديل)

## النشر على Netlify (رابط عام مجاني)

1. افتح https://app.netlify.com/drop وسجّل دخولك (مجاني).
2. اسحب مجلد `manara-site` وأفلته في الصفحة.
3. بعد ثوانٍ تحصل على رابط مثل `https://xyz-abc-123.netlify.app`.
4. لتغيير اسم الرابط: Netlify → Site settings → Change site name
   (مثال: `manara-ksa.netlify.app`).

### تحديث التطبيق بعد تعديل `app.html`

1. انسخ الملف: `Copy-Item app.html manara-site/index.html`
2. في Netlify: قم بسحب وإفلات مجلد `manara-site` مرة أخرى فوق نفس الموقع
   (Deploys → Drag and drop) — الرابط يبقى نفسه.

## بيانات المالك (لوحة الإعدادات)

- البريد: `admin@manara.edu`
- كلمة المرور: `admin123`

يمكن تغييرها من لوحة الإعدادات داخل التطبيق (زر "دخول المالك" في شاشة الدخول).

## تفعيل الدفع الحقيقي عبر Moyasar

1. أنشئ حساب تاجر في **https://moyasar.com/ar** ثم الداشبورد: https://dashboard.moyasar.com/register/new.
2. خذ **Publishable API Key** من الداشبورد (يبدأ بـ `pk_test_` للتجربة أو `pk_live_` للاستقبال الفعلي).
3. داخل التطبيق: دخول المالك → لوحة الإعدادات → قسم "بوابة الدفع (Moyasar)":
   - الصق المفتاح في "مفتاح النشر".
   - في "رابط العودة" ضع رابط موقعك (مثال: `https://manara-ksa.netlify.app`) أو اتركه فارغاً ليُستخدم الموقع الحالي تلقائياً.
   - اضغط "حفظ الإعدادات".
4. جرب أولاً بمفتاح تجريبي وبطاقات الاختبار من https://docs.moyasar.com/guides/card-payments/test-cards
   (مثال: `4111111111111111` / أي تاريخ مستقبلي / أي CVV).
5. للاستقبال الفعلي استبدل المفتاح بـ `pk_live_...` — **يتطلب موقعاً HTTPS** (Netlify يوفره تلقائياً).

> ملاحظة أمنية: مفتاح النشر آمن للوضع في التطبيق. أما **Secret Key** فلا تضعه أبداً في الكود — يُستخدم فقط من خادم للتحقق من الدفع. بدون خادم، يتم تأكيد الدفع عبر صفحة العودة؛ ويُسجل كل مبلغ تلقائياً في داشبورد Moyasar.

## بطاقات اختبار Moyasar

- بطاقة ناجحة: `4111111111111111`
- بطاقة مرفوضة: `4000000000000002`

## التجربة محلياً

- ببساطة افتح `app.html` بالنقر المزدوج، أو
- شغّل خادماً محلياً (اختر واحداً):

```
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.
